#### How to extract and save links inside a webpage 

This is a feature that existed very long ago back to the old internet era. Now browsers no longer provide the feature to directly save a webpage for either offline use, or just save it directly. That is, including saving all images and links for future use. 

Although this program does not provide the feature of automatically saving anything else on its own, it will display all url links that is in the webpage and print it out, if you provide it with the source code of that webpage. Then you can decide what pages you want to save on your own, and what you want to do with it. For example, using the information to download the links either by hand, or paste them to the command line
